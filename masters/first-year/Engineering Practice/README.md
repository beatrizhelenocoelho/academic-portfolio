\# Engineering Practice



Project developed for the Engineering Practice course of the Master's Degree in

Electrical and Computer Engineering at Instituto Superior Técnico.



\## Project — NeuroHome



This work continued the development and validation of NeuroHome, a non-invasive home

monitoring system designed to support elderly people living alone.



The system aims to improve home safety while also identifying changes in daily routines

that may indicate possible health or well-being problems.



\## System Architecture



The solution uses distributed sensor nodes based on ESP32 microcontrollers installed

throughout the home.



The system monitors:



\- Occupancy and movement

\- Temperature

\- Gas concentration



Sensor information is transmitted to a Raspberry Pi 4 acting as the central gateway.



\## Data Processing



The central unit receives and processes information from the distributed sensor nodes.



The system attempts to identify:



\- Current room occupancy

\- Daily movement patterns

\- Routine behaviour

\- Deviations from typical routines



Environmental safety information is also analysed to detect conditions such as gas leaks

or unsuitable temperatures.



\## Caregiver Application



Processed data is made available through an application intended for caregivers.



The interface provides access to information including:



\- Current occupancy

\- Activity history

\- Routine deviations

\- Environmental measurements

\- System alerts

\- Device configuration



\## Validation



The project included interaction with external organisations and caregivers in order to

evaluate the usefulness and applicability of the proposed system.



Their feedback was incorporated into the analysis and validation of the solution.
