\# Control of Cyber-Physical Systems



Laboratory project developed for the Control of Cyber-Physical Systems course of the

Master's Degree in Electrical and Computer Engineering at Instituto Superior Técnico.



\## Project — Flexible Robot Arm Joint



The objective of the project was to identify, model and control a flexible robotic arm joint.



The work was divided into two main stages:



1\. System identification and model validation

2\. Controller design and experimental evaluation



\## Part I — System Identification



The first stage focused on obtaining a mathematical model of the physical plant from

experimental measurements.



The system consists of a DC motor connected to a flexible mechanical structure.



The work included:



\- Interfacing the physical plant with the computer

\- Potentiometer calibration

\- Strain gauge calibration

\- Experimental data acquisition

\- Selection of excitation signals

\- Sampling-frequency analysis

\- Signal filtering

\- Model-order selection

\- ARMAX model identification

\- State-space model identification

\- Pole-zero analysis

\- Frequency-response analysis

\- Time-domain analysis

\- Model validation



Experimental datasets were collected from the real system and processed in MATLAB.



\## Part II — Controller Design



The second stage focused on designing a controller for the identified plant.



The control system was implemented and evaluated using MATLAB and Simulink.



The project included:



\- LQG controller design

\- Quadratic cost tuning

\- Root-square locus analysis

\- Noise covariance tuning

\- Loop Transfer Recovery (LTR)

\- Closed-loop frequency-response analysis

\- Closed-loop time-response analysis

\- Reference pre-filter design

\- Experimental performance evaluation



The final controller was tested against the physical flexible-arm setup.
