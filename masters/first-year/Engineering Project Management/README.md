\# Engineering Project Management



Project developed for the Engineering Project Management course of the Master's Degree in

Electrical and Computer Engineering at Instituto Superior Técnico.



\## Project — Cruise Ship Telecommunications Infrastructure



The objective of the project was to plan an onboard telecommunications system for the

MV World Voyager cruise ship.



The proposed system was designed to provide cellular and Wi-Fi connectivity for passengers

and crew while considering the technical and regulatory constraints of a maritime

environment.



\## Technical Scope



The project included the conceptual design of:



\- Mobile communication coverage

\- Wi-Fi coverage

\- Indoor base stations

\- Antenna placement

\- Wi-Fi access-point placement

\- Cabling infrastructure

\- Telecommunications rooms

\- Satellite backhaul integration

\- Cellular shutdown mechanisms while in port



The metallic structure and compartmentalized layout of the ship were considered when

planning wireless coverage.



\## Project Management



In addition to the technical solution, a complete project-management plan was developed.



The work included:



\- Project scope definition

\- Stakeholder analysis

\- Work Breakdown Structure

\- Task scheduling

\- Resource allocation

\- Project dependencies

\- Risk management

\- Quality planning

\- Cost estimation

\- Project milestones

\- Completion criteria



Microsoft Project was used to plan and schedule project activities.



\## Objective



The final result was a technically feasible project plan that could be used as the basis for

a future implementation of the telecommunications infrastructure onboard the vessel.
