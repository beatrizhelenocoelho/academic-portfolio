\# Optimization and Algorithms



Computational project developed for the Optimization and Algorithms course of the

Master's Degree in Electrical and Computer Engineering at Instituto Superior Técnico.



\## Project Overview



The project explored several numerical optimization problems and algorithms through a

combination of mathematical analysis and computational experiments.



The work included deterministic and stochastic optimization problems, least-squares

estimation, nonlinear optimization and distributed optimization.



\## Main Problems



\### Tracking and Control-Effort Optimization



The first part studied an optimization problem involving a target trajectory.



The work included:



\- Numerical solution for a deterministic target

\- Analysis of the relationship between tracking error and control effort

\- Proof of solution uniqueness

\- Random target optimization

\- Problems with incomplete information

\- Additional constraints

\- Optimization with information becoming available during execution



\### Circle Fitting



The second part studied the problem of fitting a circle to a set of data points.



Different approaches were analysed and compared.



The work included:



\- Analysis of the non-convex circle-fitting formulation

\- Least-squares estimation

\- Non-uniform datasets

\- Levenberg-Marquardt optimization



\### Distributed Optimization



A distributed version of the circle-fitting problem was also implemented.



The solution used optimization techniques including:



\- Augmented Lagrangian Method

\- Block Coordinate Descent



This allowed different parts of the optimization problem to be solved collaboratively.



\## Project Contents



The report contains both the mathematical derivations and the numerical code used to

evaluate the proposed solutions.
