\# Computer Architecture



Laboratory work developed during the Computer Architecture course of the

Bachelor's Degree in Electrical and Computer Engineering at Instituto Superior Técnico.



\## Overview



The laboratory assignments focused on understanding how programs are executed

at processor level, using RISC-V assembly and analysing processor performance,

pipelining and cache behaviour.



\## Laboratory Work



\### Lab 1 — RISC-V Assembly



Introduction to assembly programming and manipulation of data stored in memory

and processor registers.



The exercises include:



\- Arithmetic operations

\- Array and variable access

\- Load and store instructions

\- Conditional execution

\- Branch instructions



\### Lab 4 — Pipelining and Hazards



Analysis of instruction execution in a five-stage processor pipeline.



The work included:



\- Identification of data hazards

\- Resolving hazards using NOP instructions

\- Instruction reordering

\- Comparison of processor behaviour with and without forwarding

\- Analysis of IPC and useful-instruction ratios



\### Lab 5 — Cache Memory



Study of cache organisation and memory access behaviour.



The work included:



\- Address decomposition into tag, index and offset

\- Direct-mapped cache analysis

\- Cache hit and miss behaviour

\- Conflict misses

\- Write-back and write-allocate strategies

\- Analysis of alternative cache configurations



\## Technologies and Concepts
