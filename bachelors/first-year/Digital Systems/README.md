\# Digital Systems



Laboratory projects developed during the Digital Systems course of the

Bachelor's Degree in Electrical and Computer Engineering at Instituto Superior Técnico.



\## Overview



The laboratory work focused on the design, simulation and implementation of

digital circuits using VHDL and FPGA hardware.



The assignments progressed from basic combinational circuits to arithmetic

circuits, sequential logic and finite state machines.



\## Laboratory Work



\### Lab 1 — Introduction to VHDL



Introduction to digital circuit description using VHDL, including simulation

and validation using testbenches.



\### Lab 2 — Combinational Logic



Implementation and simulation of combinational digital circuits.



The project contains components including:



\- 3-to-8 decoders

\- 4-to-1 multiplexers

\- 8-to-1 multiplexers

\- Seven-segment display interfaces



\### Lab 3 — Arithmetic Circuits



Design and implementation of binary adders.



The project includes:



\- Full adder

\- 4-bit adder

\- 8-bit adder

\- VHDL testbenches for circuit validation



\### Lab 4 — Sequential Logic



Implementation of sequential digital circuits.



The project includes:



\- D flip-flops

\- T flip-flops

\- Decoders

\- Sequential circuits

\- Clock management



\### Lab 5 — Finite State Machines



Development of a sequential system based on a finite state machine.



The project includes:



\- State machine logic

\- Timer

\- Flip-flops

\- Control logic

\- FPGA input/output interfaces



\## Hardware and Tools



\- VHDL

\- Xilinx Vivado

\- Basys 3 FPGA

\- FPGA simulation

\- Testbenches

\- Digital circuit synthesis
